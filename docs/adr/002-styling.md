# ADR-002: Стилизация — styled-components с темой-токенами

## Статус

Принято (этап 1, зафиксировано на этапе 2).

## Контекст

Задание запрещает inline-CSS и UI-библиотеки, а styled-components отмечен как плюс.
Нужны: цветовые индикаторы по порогам, split-view по медиазапросу, анимации с учётом
`prefers-reduced-motion`, единые цвета и отступы в дереве и таблице.

## Решение

- **styled-components 6** с `ThemeProvider`. Все цвета, отступы, радиусы, длительности
  и брейкпоинт split-view — токены в `client/src/shared/theme/theme.ts`; компоненты
  берут их через `({ theme }) => theme…`. Типизация темы — `styled.d.ts`.
- Состояния передаются **транзиентными пропсами** (`$selected`, `$level`, `$active`):
  они не попадают в DOM и не порождают предупреждений React.
- Глобальные правила (сброс `box-sizing`, шрифт, `:focus-visible`,
  глобальное отключение анимаций при `prefers-reduced-motion`) — в `GlobalStyle`.
- Запрет inline-стилей закреплён правилом ESLint: атрибут `style` в JSX — ошибка сборки
  (`no-restricted-syntax` с селектором `JSXAttribute[name.name='style']`).

## Альтернативы

- **CSS Modules.** Тоже без runtime, но динамика (цвет по значению, отступ по уровню)
  ушла бы в CSS-переменные через `style=`, что нарушает требование «никакого inline-CSS»,
  либо в наборы классов — многословно.
- **Tailwind.** Не запрещён, но утилитарные классы плохо выражают вычисляемые значения
  (`padding-left` по уровню вложенности), а требование про styled-components явное.
- **Vanilla-extract / Linaria (zero-runtime).** Хорошие варианты для прода, но добавляют
  сборочные плагины; для тестового задания преимущество не окупает сложность.

## Последствия

- Runtime-стили (~12 КБ gzip) и генерация классов в браузере — для дашборда с ~60 узлами
  незаметно.
- Цвет индикатора эффективности вычисляется одной функцией `performanceColor` и одинаков
  в дереве и таблице.
