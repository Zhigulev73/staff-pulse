# ADR-006: Подсветка обновлённых ячеек через CSS-анимацию и внешнее хранилище

## Статус

Принято (этап 3).

## Контекст

Требование: обновлённые ячейки получают fade-out ~1.5 с; `prefers-reduced-motion`
уважается. Подсвечивать нужно именно ячейки (не строки), в двух представлениях
сразу (дерево и таблица), а повторное обновление той же ячейки должно перезапускать
эффект. При этом патч приходит вне React-дерева, а ячеек — сотни.

## Решение

### Хранилище подсветок вне React

`highlightStore` — маленький external store для `useSyncExternalStore`:
`Map<ключ ячейки, метка>`. Ключ — `nodeId:поле`. При патче хук `useOrgTreeLive`
вызывает `flash(keys)`, запись живёт 1.5 с и снимается одним таймером на батч.

Каждая ячейка (`FlashCell`) подписана на **свой** ключ: селектор возвращает метку
или `undefined`, поэтому при патче перерисовываются только ячейки, у которых метка
изменилась, а не вся таблица.

### Анимация — CSS `@keyframes`, перезапуск через React-key

Вспышка — `animation: flash 1.5s ease-out` от цвета подсветки к прозрачному.
Метка подсветки становится `key` элемента: новое обновление той же ячейки даёт
новую метку → элемент перемонтируется → анимация начинается заново. Не нужно ни
ловить `animationend`, ни хитрить с асимметричными `transition`.

Метки уникальны внутри хранилища (монотонно растут), поэтому два патча в одну
миллисекунду тоже перезапускают анимацию.

### prefers-reduced-motion

Глобальный стиль обнуляет длительности анимаций, поэтому для этого режима ячейка
вместо анимации получает **статичный** фон подсветки, пока запись живёт в хранилище
(те же ~1.5 с). Изменение остаётся заметным, движения нет.

## Альтернативы

- **Класс «updated» + `transition` на фон.** Симметричный переход гасит и появление
  подсветки; чтобы вспышка была мгновенной, нужны разные длительности на включение
  и выключение и таймер снятия класса — хрупко и трудно перезапускать.
- **Состояние подсветок в `App` через `useState`.** Каждый патч перерисовывал бы всё
  поддерево с новым пропом; при десятках строк это заметно, при сотнях — нет смысла.
- **Web Animations API (`element.animate`).** Работает, но требует ref на каждую
  ячейку и императивного кода в компонентах; CSS-вариант проще и декларативнее.

## Последствия

- `FlashCell` — единственное место, где живёт визуал подсветки; дерево и таблица
  используют его одинаково.
- Хранилище очищается при размонтировании live-подписки, таймеры не утекают.
- Тест-атрибут `data-flash` позволяет headless-проверкам убедиться, что подсветка
  включилась и снялась (использовано при снятии скриншотов).
